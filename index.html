01 — FUNDAMENTOS

Antes dos comandos,
entenda as ferramentas.

Git e GitHub trabalham juntos, mas não são a mesma coisa. Essa distinção é o ponto de partida.

⌘
CONTROLE DE VERSÃO

Git

É um sistema distribuído de controle de versão. Registra mudanças nos arquivos e permite recuperar versões anteriores, criar ramificações e integrar contribuições.

Executado principalmente no computador local ↗
◉
COLABORAÇÃO E HOSPEDAGEM

GitHub

É uma plataforma para hospedar repositórios Git e colaborar em projetos. Oferece Pull Requests, Issues, revisão de código e automações.

Acesse github.com ↗
i

Uma analogia: Git é o mecanismo que registra o histórico do projeto; GitHub é um espaço on-line onde esse repositório pode ser compartilhado e desenvolvido em equipe.

03 — CAIXA DE FERRAMENTAS

Comandos essenciais

Use estes comandos como referência durante os exercícios. Copie, adapte e pratique.

PRIMEIROS PASSOS

Configure sua identidade

01 / 04

Informe ao Git o nome e o e-mail que serão associados aos seus commits.

TERMINAL
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
Dica: use um e-mail associado à sua conta GitHub para facilitar a identificação das contribuições.
TRABALHO LOCAL

Crie e registre versões

02 / 04

Inicie o repositório, acompanhe as mudanças e crie um commit.

TERMINAL
git init
git status
git add .
git commit -m "Descrição da alteração"
git log --oneline
Atenção: prefira commits pequenos e mensagens objetivas, que expliquem a alteração realizada.
SINCRONIZAÇÃO

Conecte ao GitHub

03 / 04

Associe o repositório local ao remoto e envie seu histórico.

TERMINAL
git remote add origin URL_DO_REPOSITORIO
git branch -M main
git push -u origin main
git pull
Conceito-chave: push envia commits; pull busca e integra atualizações do remoto.
DESENVOLVIMENTO PARALELO

Trabalhe com branches

04 / 04

Crie uma linha independente de desenvolvimento e publique-a.

TERMINAL
git switch -c nova-funcionalidade
git branch
git add .
git commit -m "Adiciona funcionalidade"
git push -u origin nova-funcionalidade
Próximo passo: abra um Pull Request no GitHub para propor a integração da branch à main.
